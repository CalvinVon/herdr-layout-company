# Column sidebar

Used by the personal Office and agent-columns layouts.

- Click titles to fold or expand Spaces, Agents, folder groups, tabs with split sessions and agent status groups. Project chevrons show and toggle the folded state. Title hit targets handle clicks directly and stop propagation. Whole-block folding keeps a 38px header and restores its previous size on expansion.
- Each displayed group is one native Space. Its project is bound to the machine and canonical repository root; non-Git directories use their physical absolute path. Git worktrees share that project. Changing a terminal's current directory does not change its Space, project label or remembered worktree. Existing duplicate Spaces keep their tabs and panes; metadata identifies their primary container without migrating sessions.
- Tab navigation, pane navigation, contextual menus and split-agent buttons still target the original core space, tab and pane. Split groups have a disclosure arrow, layers icon and pane count even when folded. Expanded groups show each visible session's own time and completion state; a header representing a parent agent shows that parent's state. Folded groups show the aggregate status and elapsed time.
- Session rows show their Git branch even in the Space's main worktree. A folded split group shows a branch only when all its panes belong to the same worktree; detached worktrees have no branch label.
- Session rows show the latest available native status-change time, distinct from the blue working-duration counter; it is hidden while the session is working. Titles and secondary text fade after 48 hours. Today is labeled `今天`. Missing timestamps show `—` and do not trigger fading; this is not a message-update timestamp. Dates use local time and refresh at least once a minute.
- Each Space is contained in a rounded card with a color rail matching its avatar. The active Space has a stronger background and outline; focused and completed session rows retain their own highlights. Working sweeps use the Space color; a folded Space displays a sweep when any contained session is working. Selecting a different window expands its Space.
- The sidebar publishes `workspace.tab-labels` through the existing one-second refresh; Office's personal `project-tabs` bar consumes the same titles and aggregate states. Automatic names follow the lead agent's live title, explicit names remain unchanged. Session icons stay still; a bouncing blue dot for Working and a fixed green dot for Done appear at the icon's lower right in the sidebar and pane headers. Mixed split groups use the layers icon. Long top-bar titles expose the full name in a tooltip.
- Session pane headers show the live session title, followed by the agent name in parentheses when available; long titles expose their full text on hover.
- Clicking a Space header, avatar, title or chevron opens its home when it has no other tabs; otherwise it folds or expands its sessions. The drag handle sits at the right of the header, appears on hover or keyboard focus, and supports Up/Down reordering within a machine.
- Project groups follow Herdr's saved Space order. Drag the handle to reorder within a machine; the insertion line marks the upper or lower half of the target card, including expanded cards. Releasing outside the sidebar cancels the drag. Tabs, panes and the Idle agent list sort by descending native activity timestamps; timer redraws do not count as activity.
- Bindings persist in `project-bindings.json` under the Herdr app home. Git metadata refreshes at most once per repository every 5 seconds, including every folder in a Space; unavailable machines keep their last known metadata. The sidebar publishes `workspace.office-groups` in Space order, which Office preserves in its overview.
- In Office layout, the selected office outlines its matching Space card; hovering an office highlights the corresponding card without changing the active Space. Tab rows use backgrounds instead of nested selection borders.
- Agent cards and pane headers show root and worker icons. Sidebar child-session tooltips identify the recorded parent. A split group whose panes all belong to one parent uses that parent as its header; mixed groups remain Tab groups. The relation follows Herdr's terminal parent field.
- Claude Code running in a local macOS Herdr terminal reports lifecycle states through `~/.claude/hooks/herdr-core-state.py`; newly started sessions load the hook from Claude settings. Background subagents are not tracked separately by this hook.
- Native commands for the same disclosure controls: `herdr-app do agent-columns-spaces.toggle-block` and `herdr-app do agent-columns.toggle-block`.
- In Office, Cmd+B and the sidebar button hide the sidebar completely; Cmd+B restores it.
- Both layouts have a 480px right Git panel with History / Changes tabs. History uses the personal `git-history` mod to draw commit nodes, colored branch/merge edges and ref labels; clicking a commit opens its metadata and diff. Changes retains Herdr's native working-tree view and Commit action. Office opens the panel with the Changes toolbar button; agent-columns uses its Git header button. The panel follows the focused terminal's repository/worktree.
- Project creation uses a shared request queue. Opening an existing project selects its primary Space; choosing an agent there starts the requested command. Worktree sessions create Tabs in that Space; splits retain their original Tab and project. Personal `project-tabs`, `project-pane` and `project-menu` clones route visible creation controls through `agent-columns-new-menu` and `project-worktree`. Both layouts set `terminal_menu` to `project-menu`. These adapters do not intercept Herdr's global built-in commands.

Validation: `node self-check.cjs` here, `herdr-app check` for both sidebar mods, then inspect the live window and exercise both disclosure controls.
