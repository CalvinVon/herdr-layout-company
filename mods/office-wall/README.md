# 办公室信息墙

办公室墙面直接展示服务地址、二维码、当前选中 Agent 的会话目标，以及固定或由 Agent 发布的内容。二维码优先使用终端原码；原码不可用时根据服务地址生成并标注「链接二维码」。点击墙面可查看详情、复制或打开地址、定位终端，以及添加、固定或移除卡片。

当前会话目标固定为墙上第一张卡片，随活动终端切换，优先取自可唯一定位的本地 OMP 会话最近请求，否则显示已知会话标题；无法确定归属时不猜测。主 Agent 的 TODO 清单显示在信息墙标题下的黑板上，按所属分支更新，可在黑板内上下滚动。在办公室场景其他区域滚动鼠标滚轮可左右移动场景。手动内容支持链接、便签和本地文件；HTML 文件点击后由系统默认应用打开。移除卡片不会删除源文件。

手动固定卡保存在本机 Herdr 数据目录的 `office-wall-pins.json`，按房间隔离；保存卡片内容及必要来源，不保存终端输出。读写失败会显示在面板中；文件格式不受支持或并发修改同一卡片时不会覆盖原文件。地址、二维码和便签可能包含敏感信息，请只固定需要保留的内容。

服务快照由办公室通过临时文件提供；移除未固定的服务卡会通知采集器隐藏该实例。状态未知不代表服务正在运行，手机能否访问链接取决于网络和服务的绑定地址。

Agent 可从自己的 Herdr 终端将重要内容发布到所属项目办公室；命令会依据当前终端自动识别房间：

```bash
node ~/.config/herdr-app/mods/agent-office/agent-publish.cjs pin --title "关键结论" --text "需要保留的信息"
node ~/.config/herdr-app/mods/agent-office/agent-publish.cjs pin --title "可视化报告" --file /absolute/path/report.html
```

Agent 发布的卡片会自动出现，移除时只删除发布记录，不删除原文件。未明确发布的消息和产物不会自动上墙。

QR 编码器基于 Kazuhiko Arase 的 JavaScript QR Code Generator，许可证见 `QR-LICENSE.txt`。
