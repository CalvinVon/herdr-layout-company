# Herdr Layout Company

Herdr App 的 `office` 和 `agent-columns` 布局快照，包含布局、预览图、主题和所需 mod。`agent-columns` 与 `office` 共用侧栏、顶部标签栏、Files、Editor 和 Magpie 窗格，省略办公室场景。

浅色主题使用 `macos-light`：雾灰色窗口框架、白色内容面、系统蓝选中态，以及浅色标签和 Magpie 卡片的细边框与轻投影。`office` 与 `agent-columns` 共用主题；深色继续使用 Atom One Dark。状态色由各自主题提供，浅色终端的 ANSI 色与小字号状态文字使用更深的配色以保持可读性。安装时需同时复制 `themes/` 中的两个主题文件。

Office 场景按整体缩放比例适配容器，与工作区之间不额外留垂直内边距；工作区保留水平边距和窗格间距。新建会话的工作目录列表独立滚动，不带动外层页面。

Space 首页的快速启动按可用宽度显示 4、2 或 1 列，同一行由原生 flex 均分宽度，避免第四张卡片因手算宽度误差意外换行。

Office 的二维码按矩阵和显示尺寸复用不可变原生 Path；人物配色沿用工位状态，切换焦点时不重复生成。每次渲染仍创建新的元素。回归检查：`node mods/agent-office/qr-render-check.cjs`、`node mods/agent-office/self-check.cjs` 和 `herdr-app check mods/agent-office`。

目录绑定和分屏请求由始终挂载的协调器处理，隐藏 Spaces 侧栏后仍可从已有目录创建分屏。黑板标题与交付数量共用一行，目标链接下方用分隔线划分文件列表；文件行垂直居中，列表在固定区域内独立滚动，不带动办公室场景。

侧栏所有活动动效保留：工作会话与折叠项目继续播放流光，流光统一使用主题的 `working` 状态色，与会话窗格一致；Space 头像仍保留各项目配色。工作状态点继续脉冲。静态行内容、图标、流光、状态点与计时文本分为独立视图，动画相位只通知流光子视图，计时只通知时间子视图；数据变化即时显示，稳定后复用缓存。隐藏侧栏或窗口失活时暂停展示计时器，后台项目协调器继续运行。此版本需要支持 `Entity.cached()` 及兄弟视图缓存复用的定制 Herdr 原生构建，不能直接覆盖到缺少该接口的发行版。回归检查：`node mods/agent-columns-spaces/timer-check.cjs`、`node mods/agent-columns-spaces/retained-check.cjs`、`node mods/agent-columns-spaces/readiness-check.cjs` 和 `herdr-app check mods/agent-columns-spaces`。
侧栏 hover 只更新当前行的操作/时间区或当前 Space 标题，逐行缓存不再因其它会话的 hover、状态采集时间戳而整体失效。浮层复用固定 Agents 实例的状态轮询，隐藏、折叠和失活的 Agents 展示停止扫描与计时重绘。相关回归：`node mods/agent-columns-spaces/self-check.cjs`、`node mods/agent-columns/timer-check.cjs`。

流光的缓存子视图根节点显式占满行区域，外层覆盖层固定在行的左上角，避免独立根布局时仅依赖绝对定位四边而丢失绘制尺寸。

分屏标题栏采用 A+D：左侧用琥珀色感叹号表示待交互、10px 实心蓝点表示运行中、绿色勾号表示 Done、灰色空心点表示 idle；悬停与无障碍标签保留状态文字。待交互标题栏每 2 秒进行一次暖色背景呼吸，文字保持稳定，悬停标题栏时显示明确的“最大化 / 还原”文字按钮；运行中使用极淡蓝色底、蓝色半粗体标题和局部扫光。所有状态保持中性细分隔线，不再显示右侧实色徽标。idle 标题栏不绘制背景，聚焦时也保持透明；未聚焦的 idle 标题使用低强调色的 90% 不透明度，角色图标和终端 ID 同时降低强调度，聚焦后恢复文字对比度。标题按内容占位，目录紧邻标题；窄分屏中两者仍可收缩，避免标题预留弹性宽度导致中间出现大段空白。当前原生接口没有按单个分屏状态调整正文透明度或蒙层的能力，标题栏 mod 不能覆盖终端正文。

每个运行中标题栏只保留一条原生扫光，复用侧栏渐变资源；每个待交互标题栏只对背景透明度做一次原生循环，左侧状态信号和文字不叠加动画。原生循环仍约 30fps，慢周期不代表更低绘制帧率，不承诺 CPU 降幅。复用原有 1 秒生命周期检查，状态稳定时不触发重渲染，窗口失活后至迟在下一次检查移除动效；隐藏副本由原生停止绘制，idle 和 Done 不含循环动画。移动菜单不启动标题栏检查。回归检查：`node mods/project-pane/attention-check.cjs` 和 `herdr-app check mods/project-pane`。

布局包含 Magpie 窗格，可通过顶部 Magpie 图标显示或隐藏。窗格连接本机 Magpie 网关，展示路由、额度和用量；总览随浅色或深色主题调整样式，区块可拖动手柄排序、固定或隐藏，已隐藏区块可从顶部恢复；额度卡片用进度条、百分比和配速展示各窗口。额度区域实际宽度达到 200px 时使用两列，更窄时一行一张卡片；悬停来源图标会在原位显示“×”，管理模式下直接显示移除或恢复入口。左右箭头按可见卡片前后移动，自动跳过已隐藏来源及无可见额度项的卡片。“来源额度”旁的“重置”恢复全部来源和额度项，保留排序及固定状态；这些显示设置在本地保存，并在固定面板与侧边浮层间同步。

实时路由只列出当前会话的请求卡片，标题沿用会话名称，计数与卡片一致；无法识别当前会话时退回列出全部活动会话，“全部活动路由”仍展示所有来源与来源关系。回归检查：`node mods/magpie-live/render-check.mjs`。

固定区和未固定区都按内容的自然高度参与原生 flex 布局，不再设置固定区像素高度或 40% 比例上限。空间足够时固定区完整展示；两边内容合计超出窗口时按自然高度收缩并分别滚动。窗口缩放或内容变化直接由原生布局重算，取消高度测量及其重渲染反馈。

Magpie 隐藏区块按需构建，用量页只读取用量、额度和历史；切回总览立即补刷路由。成功的本地会话识别最多复用 15 秒，进程或报告身份变化立即失效，未识别结果继续重试。走势图和额度派生按数据、时间桶与尺寸更新；保留原有路由动效、逐点提示和固定/浮层设置同步。Office 失活时暂停常规采集，恢复后由 500ms 检查补刷，显式操作仍可执行；总览广播不包含 Agent 标题。稳定项目根的常规 worktree 检查间隔为 30 秒，显式项目操作沿用即时校验；隐藏固定侧栏和失活窗口不运行展示计时器，独立项目协调器继续处理请求。

顶部工具栏可在“插入”和“悬浮”之间切换 Files、Changes 和 Editor 的显示方式；已打开的面板随模式切换继续显示，Files 保留当前文档与预览/源码状态，Changes 保留 History 选择，Editor 沿用同一个终端。悬浮窗口默认居中，只能从标题栏拖动，内容区保留原生文字选择和复制。关闭窗格后，顶部按钮同步取消高亮，再次点击即可重新打开。

Files 支持文档内查找：`⌘F`（`keys.json` 的 `global` 绑定 `files-markdown.find`）或标题栏“查找”打开查找栏。Markdown 预览按渲染后的正文匹配，源码按编辑器内容匹配；输入查询、`↑`/`↓` 或 Enter/Shift+Enter 都由原生组件高亮并滚动到当前匹配项，预览异步解析时显示“正在定位”。`×` 关闭并清除高亮；切换文件会关闭查找。此版本需要提供 `TextViewState.markdown()`、`TextView.new()` 和 `EditorState.search()` 的 Herdr 原生构建，先更新原生程序再安装此 mod。回归检查：`node mods/files-markdown/find-check.cjs`、`node mods/files-markdown/selection-check.cjs`。

Files 通过 `nextCommand()` 接收 `files-markdown.find`；仅配置快捷键不足以打开查找栏。重复调用会重新聚焦当前查找框。

Files 的源码链接支持 `路径:行号` 和 `路径:行号:列号`；点击后进入源码视图、定位目标行并短暂高亮，重复跳转同一文件不重新加载。原生终端通过 `{path, line, column}` 保留定位信息，固定面板与悬浮 Files 都接收。此功能需要提供 `EditorState.reveal_line()` 的定制 Herdr 原生构建，更新后重新打开应用再使用。定位回归：`node mods/files-markdown/line-link-check.cjs`。

标题栏拖动使用 Herdr 原生窗口的 `drag_handle` 接口。使用 Herdr v0.1.13 源码时，可将 [原生补丁](docs/herdr-v0.1.13-title-drag.patch) 应用到源码根目录，然后重新构建 Herdr。

顶部搜索和 `Cmd+P` 使用 `workspace-picker`，可按 hc ID、角色/标签（如“测试”“#验收”）、会话名称或 Space 名称搜索；多个空格分隔的词同时匹配同一会话。结果展示 hc ID 和角色，选择分屏会直接聚焦该分屏；未固定的子 Agent 也可搜索。安装时将现有 `keys.json` 的 `global.cmd-p` 合并为 `mod.open:workspace-picker`，保留其它键绑定。

工位不再显示 Git 分支便签，改为展示已关联到该工位的文件：Markdown 为蓝色、HTML 为橙色、PDF 为红色，其它类型为绿色。显示前三份文档，更多文件通过“+N 份文档”查看；悬停显示完整路径，点击打开对应文件。文件沿用发布记录中的作者/工位归属，不根据共享工作目录猜测归属；没有可靠作者信息的旧记录仍在项目文件墙保留。

Agent 可执行 `node ~/.config/herdr-app/mods/agent-office/agent-publish.cjs pin --title "技术方案" --file /绝对路径/plan.md` 发布文件，脚本自动记录当前 hc 会话和工位。子 Agent 没有独立工位时关联到可核验的父工位，离开的会话不会把文件转给后来复用同一 ID 的会话。

侧边栏或 Magpie 面板被隐藏时，鼠标移入窗口左右边缘 16px 范围会临时覆盖展开面板，不改变中央区的布局或终端尺寸；触发范围随界面缩放同步调整。侧边栏浮层宽度至少为 440px（受布局上限及窗口宽度约束），以便看全会话名称；鼠标移开后稍作延迟收起，移回面板可取消收起。点击原有的显示按钮可恢复固定面板。
左侧边缘触发器为零宽度，不显示常驻边条或把手；侧栏隐藏时仍由窗口左边缘 16px 的指针检测临时展开，`⌘B` 显示/隐藏固定侧栏。Office 和 agent-columns 共用该行为。回归检查：`node --experimental-vm-modules mods/edge-drawer/render-check.mjs`、`herdr-app check mods/edge-drawer`。

Magpie 浮层沿用固定面板的宽度，并共享页签、图表选项、区块顺序、固定和隐藏设置；在任一展示方式中调整后，另一处同步更新。

侧边浮层使用 Herdr 原生圆角、细边框和柔和投影，与中央内容自然区分。

路由图按 Agent 类型和供应商汇总全部活动请求；实时路由区块将当前会话置顶并高亮，以会话名称为卡片标题，展示模型、路由组、原因、耗时和会话用量统计。路由组名称来自 Magpie 配置，未找到时显示组 ID。识别失败时会在刷新时重试；Pi 会话文件未保持打开时，按工作目录和完整会话标题唯一匹配。多个会话同名时不猜测归属。有活动请求时不重复展示借用该会话的状态卡，识别出的当前会话没有活动请求时仍显示状态。

实时路由按会话合并卡片，同一会话的并发请求仍逐项显示；可通过本机进程会话文件唯一关联时展示对应的 hc ID，无法确认时不猜测。

用量概览和用量走势是独立区块，可分别固定、隐藏和排序。走势可切换请求、Token、费用，以及按小时或按天：按小时显示今天，按天显示近 7 天；概览选择 30 天或全部时，按天显示近 30 天。图表粒度不改变概览周期；仅图表与概览周期一致且历史足够时显示前周期对比。7 天和 30 天的对比包含今天尚未结束的部分；历史不足、基准为零或费用部分未计价时不显示误导性的比较。

Magpie 路由图使用静态连线与状态点，不再持续移动圆点；隐藏的路由图、实时路由和请求列表不构建元素。用量与额度历史柱图合并为原生 Path，保留逐时段 tooltip、前周期对照、圆角与未计价提示；派生数据和几何按数据、时间桶或尺寸变化更新。仅近期请求变化不重建用量页，成功读取时间由独立子视图更新。

Magpie 本地检查：`node --experimental-vm-modules mods/magpie-live/render-check.mjs`、`node mods/magpie-live/usage-comparison-check.mjs`，以及 `herdr-app check mods/magpie-live`。前两项检查刷新、数据与图形描述；原生 check 仅验证初始描述，不能代替实际布局、截图和 CPU A/B。优化依据、实施结果与验证边界见 [Magpie CPU 方案](docs/magpie-cpu-plan.md)。

## 交给 Agent 安装

复制下面的提示词：

```text
请从 https://github.com/CalvinVon/herdr-layout-company 安装 office 布局到我的 Herdr App：先检查我的 Herdr 版本、配置目录，以及原生构建是否支持 Entity.cached()、兄弟视图缓存复用、TextViewState.markdown()、TextView.new() 和 EditorState.search()；缺少接口时先报告兼容性缺口，不覆盖正在使用的侧栏或 Files。兼容时备份将被覆盖的同名布局、主题及 mod，再安装仓库中的对应文件，保留我的会话和项目数据；检查 mod 是否能够加载，切换到 office 布局并验证运行状态，最后告诉我如何恢复备份及任何兼容性问题。
```
