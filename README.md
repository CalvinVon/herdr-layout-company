# Herdr Layout Company

Herdr App 的 `office` 布局快照，包含布局、预览图、主题和所需 mod。

布局包含 Magpie 窗格，可通过顶部 Magpie 图标显示或隐藏。窗格连接本机 Magpie 网关，展示路由、额度和用量；总览区块及额度卡片可排序、隐藏，设置保存在本地。
