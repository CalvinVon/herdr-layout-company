三种不同层级

按照目录
实际工作目录 → 子目录 → 该目录的 Agent。直接跨 tab 收集，不插入会话或 Team 层。

Team
Team → 主 Agent → 下级 Agent → 更下级 Agent。跨 tab、跨目录的成员仍按 Team 上下级排列。

默认
界面 tab → 该 tab 的全部分屏。保持 tab 内顺序，父子关系不改变这个视图。

视觉收敛
无描边、无左侧色块。非当前行和右侧辅助文字降低强调度，运行中的蓝色状态保留。数量只显示数字。

同一批示例 Agent 在三种视图中的位置不同。点击分组会聚焦其中的 Agent；「＋」带入对应目录。仅为独立 HTML 原型。
